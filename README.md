# 🥃 Alambique Risadinha — Site Oficial

Site institucional do **Alambique Risadinha**, produtora de cachaça artesanal localizada em **Piranga, Minas Gerais**, com mais de **77 anos de tradição**.

---

## ✅ Funcionalidades Implementadas

### Páginas
| Arquivo | Descrição |
|---------|-----------|
| `index.html` | Home com Hero, Sobre, Diferenciais, Produtos em destaque, Contador animado, Depoimentos e CTA |
| `produtos.html` | Página detalhada dos 3 produtos com filtro interativo |
| `sobre.html` | História da empresa, timeline, processo de produção e valores |
| `contato.html` | Formulário de contato, informações, horários e redes sociais |

### Componentes e Recursos
- **Age Gate** (verificação de maioridade com `sessionStorage`)
- **Navbar responsiva** com scroll effect + menu hamburger mobile
- **Hero section** com parallax suave e partículas animadas
- **Contador de estatísticas** animado (77 anos, 3 produtos, 100% artesanal, 1947)
- **Slider de depoimentos** com autoplay e controles
- **Animações on-scroll** (Intersection Observer nativo)
- **Filtro de produtos** na página de produtos
- **Formulário de contato** com feedback visual de sucesso
- **Timeline histórica** interativa (página Sobre)
- **Processo de produção** passo a passo (página Sobre)
- **Footer completo** com links, redes sociais e aviso legal
